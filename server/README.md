# Mapeleven map server

One Docker Compose stack that serves everything the SDKs need:

| Path | What | Software |
|---|---|---|
| `/tiles/mena.json`, `/tiles/mena/{z}/{x}/{y}.mvt` | Vector tiles | go-pmtiles over a Protomaps extract |
| `/styles/{theme}-{lang}.json` | MapLibre styles (5 themes x ar/en) | generated by `styles/build.mjs` |
| `/assets/fonts`, `/assets/sprites`, `/assets/rtl` | Glyphs (incl. Arabic), icons, RTL plugin | protomaps/basemaps-assets |
| `/search/api`, `/search/reverse` | Search and reverse geocoding | Photon |

Caddy in front handles HTTPS (Let's Encrypt), CORS and caching.

## Sizing

The default bounding box covers Jordan and the GCC (Arabian Peninsula). Zoom 0 to 15 is a few GB.
A Hetzner cloud server with 4 vCPU, 8 GB RAM and 80 GB disk is enough for tiles and search;
a larger region mostly costs disk for tiles and RAM for Photon (raise `PHOTON_HEAP`).

## Setup

```bash
git clone https://github.com/yehyatt/mapeleven && cd mapeleven/server
cp .env.example .env              # set DOMAIN, REGION_BBOX, ...
./scripts/extract-tiles.sh        # region cut from the latest daily OSM planet build
./scripts/fetch-assets.sh         # fonts, sprites, RTL plugin
./scripts/build-styles.sh         # styles pointing at https://$DOMAIN
docker compose up -d              # tiles + styles

./scripts/import-search.sh        # optional: Photon index for PHOTON_REGIONS (ar + en)
docker compose --profile search up -d
./scripts/import-places.sh        # optional: Overture places OSM lacks (OVERTURE_COUNTRIES)
```

Point a DNS A record for `DOMAIN` at the server before starting Caddy.

## Updating

Re-run `extract-tiles.sh` (new tiles, swapped atomically) and `import-search.sh` weekly or monthly,
then `docker compose restart tiles search`.
