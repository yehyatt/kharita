Open source · Flutter and web · MapLibre and OpenStreetMap

Open-source maps for Flutter and the web. Free key, no card.

A free alternative to Mapbox and Google Maps: vector maps on OpenStreetMap, place search, custom markers, zones and live tracking, from one SDK. Labels follow your app's language, with Arabic and right-to-left done properly. Use the hosted server for Jordan and the Gulf, or run your own for any country.

    Your language, Arabic done right

    Labels follow your app's language and switch at runtime. Arabic is shaped correctly on every platform, layouts follow RTL, and search copes with Arabic spelling variants. Press ع on the map above.

    Search and addresses

    About a million places across Jordan and the GCC: autocomplete, reverse geocoding, districts and governorates for zone matching.

    Built for delivery

    Centre-pin address picker, delivery zones, clustered stores, vehicle icons that move in real time.

    Places on the map

    Pharmacies, mosques, cafés, fuel and more come with the basemap. Tap them or list what is nearby with no server call.

    Five themes

    Light, dark, white, grayscale and black styles, so the map matches your brand and dark mode.

    Yours to host

    One Docker Compose stack on one small server: tiles, styles, fonts and search, with HTTPS. Your users' locations stay with you.

    A map in a few lines

    MapelevenMap(
  provider: MapelevenProvider.hosted(key: 'mel_...'),
  language: MapelevenLanguage.ar,
  onMapReady: (map) async {
    await map.registerIcon(await MapelevenIcon.fromIconData('truck', Icons.local_shipping));
    await map.addMarker(driver, id: 'driver', icon: 'truck');
    final places = await map.search.search('صيدلية', near: map.center);
  },
  onCameraIdle: (center, zoom) async {
    final address = await map.search.reverse(center);   // pin picker
  },
)

    Coming from Google Maps or Mapbox?

    From Google Maps, the Flutter widgets map one to one and backend geocoding becomes one new provider class. From Mapbox, little changes at all: Mapeleven runs on MapLibre, the open-source continuation of Mapbox GL. Both guides cover the code mapping, search and a safe rollout.

    What is free, and what costs money

    Free

    • The SDKs (MIT) and the server software
    • OpenStreetMap data (keep the attribution)
    • A key for the hosted service: 50,000 map loads and 50,000 searches a month, no card

    Your server

    • One 4 vCPU, 8 GB machine covers Jordan and the GCC
    • Bigger regions need more disk and memory
    • Monthly data refresh with two scripts

    Not in the box

    • Road routing and ETAs: next on the roadmap
    • Live traffic: paid data
    • Satellite imagery: works with your own Esri or MapTiler key (guide)
    • Business ratings, photos, opening hours
